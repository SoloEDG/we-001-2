# 灰烬渡口

安装：`npm ci`

本地启动：`npm run dev`，打开终端显示的地址。

Docker 启动：`docker compose up --build`，访问 http://localhost:18071。

## 战争迷雾（按阵营各自记忆）

- **视野产生**：由角色的位置与职业视距决定（游侠 6 / 秘术师 4 / 卫士·医师 3），
  占据高地（ridge）时视距 +1；视线采用 Bresenham 直线，断崖（wall）阻挡传播，
  阻挡格本身仍可见（看得见崖面），崖后不可见。
- **三态地图**：当前可见（亮色）/ 曾经探索（暗淡，保留地形）/ 未知（完全遮蔽）。
- **持久记忆**：每个阵营独立保存 `explored` 探索格与敌方 `observations` 最后观测快照，
  撤离后仍保留曾看过的河岸；记忆只增不减，不会每次按当前位置重算。
- **敌方信息**：编队只列当前可见敌人；脱离视野的敌人只在地图与列表显示“最后观测”
  虚影（位置 + 职业 + 观测时生命），不泄露其实时生命与实时位置。
- **目标限制**：技能不能以隐藏敌人为目标，合法性以**当前行动阵营**的视野为准，
  不受手动切换观察视角影响。
- **触发时机**：移动、技能（含死亡）、结束行动（灼烧等状态结算）、地形编辑都会
  刷新视野；未探索区域不可编辑地形。
- **回放**：每个事件保存一份迷雾快照（记忆 + 当时可见格），历史回放直接读取该时刻
  观测资料，不重算；切换阵营使用各自记忆，互不串用。
- **旧档兼容**：缺少迷雾记忆的旧存档会按 `初始帧 → 各事件 after` 的顺序在内存中重建；
  重建失败时安全降级且**不覆盖原档**，下一次有效行动后再正常保存。

## 视角切换

左侧“战争迷雾”面板可在苍蓝军 / 余烬军视角之间切换；“跟随当前行动阵营”开启时，
每当一方结束行动会自动切到下一行动方的视角。
